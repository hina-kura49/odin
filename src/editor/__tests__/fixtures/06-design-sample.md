# 新しいプロダクトの考え方

シンプルでありながら、日々の思考を深めることができるノートアプリについて考える。機能を足すのではなく、書く体験そのものを磨くことで、長く使い続けられる道具にしたい。

## 目指すもの

Notionほど重くなく、Obsidianよりもやさしい。ローカルで動作し、書くことに集中できるミニマルなノートアプリ。

- 素早く起動し、すぐに書き始められる
- 日本語の読みやすさを大切にする
- 日々の思考の積み重ねを、シンプルに支える

### 具体的なアイデア

1. キーボード中心の快適な操作
2. 必要なときにだけUIが現れる、静かなインターフェース
3. ローカルのMarkdownファイルで、将来も安心

## やること

- [ ] プロトタイプを作成する
- [x] ユーザーテストを実施する
- [ ] フィードバックをまとめる

> シンプルさは、複雑さよりも難しい。
> — スティーブ・ジョブズ

```ts
function hello() {
  console.log("やさしい道具を、長く。");
}
```

| 観点 | 検討内容 | 優先度 |
| --- | --- | --- |
| 使いやすさ | 起動の速さ | 高 |
| 読みやすさ | 本文の幅・行間 | 高 |
| 拡張性 | シンプルな設計 | 中 |
